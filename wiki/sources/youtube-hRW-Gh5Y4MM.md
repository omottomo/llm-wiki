## 한 줄 요약

[[entities/jev|Jev]] API 키를 받아 에이전트(Aside)에 붙이고 메일 분류·투자 판단·수능 문제 예측까지 시켜 본 사용기로, 소개 부분은 대체로 홍보 문구를 옮기고 검증은 하지 않는다.

## 핵심 내용

- API는 바로 발급되지 않고 웨이트리스트에 올라간 뒤 순차 초대되는 방식이다. 금요일 밤에 신청해 다음 날 아침에 받았다고 말한다 (2026-09 기준).
- Jev를 "말을 뱉지 않고 선택만 하는 도구"로 소개한다. 이 서술 자체는 1차 문서와 어긋나지 않는다.
- 사용법을 사람이 익히는 대신 **에이전트에게 공식 문서를 읽히고** 스킬 설치와 API 키 연결까지 맡겼다고 밝힌다.
- 쓰임새로 ① 메일을 긴급도 순으로 5개 추려 내기 ② 주식 추가 매수 판단 ③ 2027학년도 수능 수학 문제 예측 ④ 프롬프트 난이도에 따라 모델을 고르는 라우터 시제품을 보여 준다.
- 모델 라우터 아이디어는 "70개쯤 되는 모델 중에서 Jev가 매번 고르게 하고 싶었는데 현실적으로 많이 어렵더라"며 미완성임을 스스로 밝힌다.

## 주요 주장 / 데이터

- "Jev는 일반적인 LLM보다 약 **200배 빠르고 가격은 400배 싸다**고 홍보하고 있다"고 전한다. 홍보 문구의 전달이며 직접 측정은 없다.
- 투자 판단 사례에서 "추가 매수 보류 확률 0.7", "하이닉스 추가하지 마라 0.99", "확신 점수가 2점 만점에 1.96" 같은 수치를 읽는다. 마지막 값은 공식 문서의 신뢰도 정의(0~1)와 맞지 않는다 (→ [[sources/typesafe-ai-docs|#52 TypeSafe 공식 문서]]).
- 수능 예측 사례에서는 결과물 자체가 "실제 출제를 보장하지 않는다"고 적혀 나왔다고 말하고, 투자 사례에서도 "투자 참고용이고 투자 조언이 아니다"라는 응답을 받았다고 전한다.
- 에이전트끼리 대화할 때 사람이 알아볼 수 없는 방향으로 흐르곤 하는데, Jev처럼 수학적으로 표현된 선택을 끼우면 결과 품질을 어느 정도 붙잡을 수 있지 않겠냐는 **개인적 추측**을 덧붙인다. 본인도 추측이라고 밝힌다.

> 수능 문제 예측과 주식 매수 판단은 1차 문서가 약점으로 못 박은 영역과 정면으로 겹친다. 문서는 수·날짜·생성 과제를 실패 모드로 적고 신뢰도가 정답 보증이 아니라고 명시한다 (→ [[sources/typesafe-ai-docs|#52 TypeSafe 공식 문서]]). 이 긴장은 [[analysis/jev-vs-llm|Jev vs LLM vs 코드]]에 따로 정리했다.

## 기존 위키와의 연결

- 강화: 웨이트리스트 → 초대 → 콘솔에서 API 키 발급이라는 접근 경로를 [[sources/youtube-lx3YkhzM_04|#54 재브 뭐가 다른가]]와 같은 내용으로 재확인한다. "Jev는 채팅 모델이 아니라서 모델 목록이 아니라 스킬+API로 붙인다"는 대목도 1차 문서의 선 긋기와 일치한다.
- 모순: "200배·400배" 홍보 문구를 검증 없이 전한다. [[sources/youtube-GeM9URVnPV8|#55 Jev 200배 테스트]]의 실측은 6~8배였다. 배수 주장은 [[analysis/jev-vs-llm|Jev vs LLM vs 코드]]에서 단가·비교 대상과 함께 다시 계산했다.
- 신규: 없음. 이 소스 단독으로 위키에 올린 사실은 없다.
