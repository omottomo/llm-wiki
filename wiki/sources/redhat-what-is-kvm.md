# KVM이란 무엇인가 (레드햇)

## 한 줄 요약

레드햇의 KVM 해설 문서다. [[entities/kvm|KVM]]을 "리눅스를 하이퍼바이저로 동작하게 하는 오픈소스 가상화 기술"로 정의하고, VM이 리눅스 프로세스라는 설계가 무엇을 가져오는지를 중심으로 설명한다.

## 핵심 내용

- **연혁.** KVM은 2006년에 발표됐고 이듬해 리눅스 커널에 병합됐다. 레드햇 가상화 포트폴리오를 비롯한 여러 오픈소스 가상화 기술이 KVM을 구성 요소로 쓴다.
- **왜 리눅스여야 했나.** 하이퍼바이저는 메모리 관리자·프로세스 스케줄러·I/O 스택·디바이스 드라이버·보안 관리자·네트워크 스택 같은 OS 수준 부품을 필요로 한다. KVM은 커널의 일부라서 이 부품들을 이미 갖고 있다.
- **핵심 설계.** VM 하나가 곧 **평범한 리눅스 프로세스**다. 표준 리눅스 스케줄러가 스케줄링하며, 네트워크 카드·그래픽 어댑터·CPU·메모리·디스크 같은 전용 가상 하드웨어를 갖는다.
- **보안 경계.** SELinux가 VM 둘레에 보안 경계를 세우고, sVirt가 이를 확장해 게스트 VM에 강제 접근 제어를 적용한다. 수작업 라벨링 실수를 막는 것이 sVirt의 목적이다.
- **스토리지.** 리눅스가 지원하는 저장소는 무엇이든 쓸 수 있다. 공유 파일 시스템도 지원해 VM 이미지를 여러 호스트가 나눠 쓸 수 있다.
- **라이브 마이그레이션.** 돌아가는 VM을 물리 호스트 사이에서 서비스 중단 없이 옮긴다. 전원은 켜진 채, 네트워크 연결도 살아 있고, 앱도 계속 돈다.
- **관리 도구 4종** — libvirt·virsh, Virtual Machine Manager(virt-manager), Cockpit 같은 웹 콘솔, 그리고 쿠버네티스 환경용 KubeVirt.

## 주요 주장 / 데이터

- **하드웨어 아키텍처 지원.** RHEL 9의 일부로 쓸 때 64비트 AMD·Intel·ARM 아키텍처와 IBM z13 이상 시스템에서 지원된다 (2026-09 기준).
- **가상화의 이점 4가지** — 유연성, 속도(VM 구성이 소프트웨어라 생성·삭제·복제·이전이 빠름), 호환성(내 OS용으로 나오지 않은 소프트웨어도 구형 OS를 VM에 띄워 계속 씀), 안정성·안전성(VM이 망가져도 호스트와 다른 VM은 멀쩡함).
- **하이퍼바이저의 타입을 언급하지 않는다.** "리눅스가 하이퍼바이저로 동작할 수 있다"고만 쓰고, 타입 1인지 타입 2인지는 문서 어디에도 적지 않는다.
- 문서는 KubeVirt가 레드햇 OpenShift Virtualization의 토대라고 밝힌다. VM과 컨테이너화된 애플리케이션을 나란히 관리하는 것이 목표다.

## 기존 위키와의 연결

- 강화: [[entities/kvm|KVM]] 페이지의 뼈대 전체. VM이 리눅스 프로세스라는 설계, SELinux·sVirt, 라이브 마이그레이션, 관리 도구가 모두 여기서 나왔다.
- 강화: [[concepts/hypervisor|하이퍼바이저]]가 왜 OS 수준 부품을 필요로 하는지에 대한 설명. 타입 1·2 구분을 제품 이름으로만 배우면 놓치는 대목이다.
- 강화: [[concepts/kubernetes|쿠버네티스]]와의 접점. KubeVirt가 VM을 쿠버네티스 위에서 다루는 길을 연다는 사실이 이 자료로 들어왔다.
- 모순: [[entities/kvm|KVM]]의 타입 분류. 이 문서가 타입을 못 박지 않는 반면 [[sources/aws-what-is-virtualization|#35 AWS 가상화 개요]]·[[sources/oracle-virtualization-explained|#36 오라클 가상화 해설]]은 "타입 1"이라고 단정한다. 침묵은 반박이 아니지만, 세 벤더 문서가 같은 질문에 서로 다른 태도를 보이는 것 자체가 기록할 만한 사실이다.
- 신규: [[entities/kvm|KVM]] 엔티티 페이지가 이 자료로 생겼다.

## 외부 검증 (2026-09-22, 웹)

- "2006년 발표, 이듬해 커널 병합"은 [[sources/oracle-virtualization-explained|#36 오라클 가상화 해설]]의 "2007년부터 커널에 포함"과 일치한다. 서로 다른 벤더가 같은 연도를 말하므로 신뢰하고 실었다.
- 커널 쪽 1차 자료인 [[sources/kernel-kvm-docs|#42 KVM 커널 문서]]는 API가 리눅스 2.6.22부터 안정화됐다고 적는다. 병합 시점을 직접 말하지는 않지만 2007년이라는 연도와 모순되지 않는다.
