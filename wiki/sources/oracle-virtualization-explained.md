# 가상화란 무엇인가 (오라클 종합 해설)

## 한 줄 요약

오라클의 종합 가이드 문서다. [[concepts/virtualization|가상화]]의 정의·이점·구성요소를 훑은 뒤, 다른 벤더 문서가 잘 다루지 않는 **운영상 과제**와 **앞으로의 방향**까지 따로 절을 두고 정리한다.

## 핵심 내용

- **정의.** 전용 소프트웨어로 컴퓨트·스토리지·네트워크 자원을 분리해, 하드웨어를 공유하면서도 각자 OS와 앱을 돌리는 여러 워크로드에 나눠 준다.
- **핵심 요약 4줄.** 하드웨어 활용도 최적화, 유연성·격리 보안·재해 복구, 온프레미스와 클라우드 양쪽의 확장성 기반, 그리고 리소스 경합과 VM 스프롤 같은 과제 관리가 전제 조건이라는 것.
- **하이퍼바이저 두 타입에 제품을 붙여 설명한다.** 타입 1의 예로 Oracle Linux KVM을, 타입 2의 예로 Oracle VirtualBox와 VMware Workstation을 든다.
- **운영상 과제 7가지** — 리소스 경합, 보안 위험, VM 스프롤, 백업·복구 복잡성, 라이선스·컴플라이언스, 복잡한 관리, 네트워크 병목.
- **가상화 종류 6갈래** — 서버·데스크톱·데이터·스토리지·애플리케이션·NFV. 데이터 가상화를 "데이터 페더레이션"이라고도 부른다고 밝힌다.
- **마이그레이션 두 방식** — 라이브 마이그레이션(VM을 켠 채 메모리와 상태를 새 호스트로 옮김)과 콜드 마이그레이션(전원을 끄고 옮김).
- **앞으로의 방향 3가지** — DPU·SmartNIC 같은 전용 실리콘으로의 이전, 베어메탈 서비스, 마이크로VM.

## 주요 주장 / 데이터

- **마이크로VM.** 전통적 VM이 부팅에 수 분이 걸리고 완전한 OS를 요구하는 데 반해, 마이크로VM은 불필요한 것을 모두 걷어내고 **밀리초 단위로 부팅**한다. 덕분에 물리 서버 한 대에 격리된 작업 수천 개를 안전하게 담을 수 있다고 주장한다.
- **DPU·SmartNIC.** 하이퍼스케일러가 보안·격리·가상 네트워킹 같은 클라우드 기능을 별도 카드로 넘기고, 서버 CPU는 애플리케이션에만 쓰게 하는 흐름을 짚는다.
- **베어메탈 서비스.** 물리 서버에 클라우드 VM의 자동화·프로비저닝·네트워크 통합을 얹어, 가상화 계층의 지연에 민감한 워크로드를 겨냥한다.
- **하이퍼바이저의 동작 묘사.** 가상 환경에서 추가 자원이 필요한 명령이 나오면 하이퍼바이저가 요청을 물리 시스템에 넘기고 변경을 캐시에 저장하며, 이 모든 과정이 네이티브에 가까운 속도로 일어난다고 적는다.
- **FAQ의 KVM 서술.** KVM을 "리눅스 시스템을 타입 1(베어메탈) 하이퍼바이저로 바꾸는 오픈소스 기술"로 규정하고, 2007년부터 리눅스 커널에 포함됐다고 적는다.

## 기존 위키와의 연결

- 강화: [[concepts/virtualization|가상화]]의 운영상 과제 절 전체가 이 자료에 기댄다. 다른 벤더 문서가 이점만 나열하는 자리에서 이 문서는 대가도 함께 적는다.
- 강화: [[analysis/vm-vs-container|가상 머신 vs 컨테이너]]의 마이크로VM 대목. "밀리초 부팅"이라는 개괄 주장은 [[sources/virtio-and-firecracker-docs|#43 virtio·파이어크래커]]의 구체적 수치와 맞물린다.
- 모순: [[entities/kvm|KVM]]의 타입 분류. 이 문서는 [[sources/aws-what-is-virtualization|#35 AWS 가상화 개요]]와 같은 편에 서서 "타입 1"이라고 단정하지만, [[sources/wikipedia-virtualization-foundations|#40 위키백과 가상화 기초]]는 구분 자체가 흐릿하다고 본다.
- 신규: [[concepts/virtualization|가상화]]의 "운영상 과제"와 "앞으로" 두 절이 이 자료로 생겼다.

## 외부 검증 (2026-09-22, 웹)

- 커널 병합 시점을 "2007년"으로 적은 것은 [[sources/redhat-what-is-kvm|#37 레드햇 KVM]]의 "2006년 발표, 이듬해 커널 병합"과 맞아떨어진다. 두 벤더가 독립적으로 같은 연도를 말하므로 [[entities/kvm|KVM]] 연혁에 그대로 실었다.
- 마이크로VM의 "밀리초 부팅"은 벤더 마케팅 문구일 수 있어, 1차 자료인 [[sources/virtio-and-firecracker-docs|#43 virtio·파이어크래커]]의 생성률 수치로 교차 확인한 뒤에야 위키에 실었다.
