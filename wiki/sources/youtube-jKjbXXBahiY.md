## 한 줄 요약
클로드 데스크탑 앱의 대화창과 코워크(Cowork) 기능만으로 코딩 없이 주식 종목 분석 AI 에이전트 팀(오케스트레이터 + 서브에이전트)을 만들고 예약 실행까지 거는 실습 영상.

## 핵심 내용
- 전제: 에이전트는 "역할 정의 + 행동 규칙 + 출력 형식"으로 자동 작업하는 것이며, 앤트로픽은 이를 하나의 마크다운 파일로 정의하도록 권고. SDK 설치·클로드 코드 학습 없이 클로드 AI 대화창만으로 가능.
- 제작 흐름: 클로드 채팅에 "주식 종목 분석 에이전트를 앤트로픽 공식 에이전트 가이드에 따라, YAML 프런트매터 + 마크다운 시스템 프롬프트로 만들어 줘"라고 요청. description에 "proactive use"를 넣어 적절한 에이전트가 자동 호출되게 함.
- 오케스트레이션 구조: 단일 MD가 아니라 한 명의 "팀장(오케스트레이터)"이 여러 서브에이전트 MD를 돌리는 다중 파일 구조가 더 효율적. 결과적으로 오케스트레이터 + 6개 서브에이전트, 총 7개 MD 파일 생성(기업 개요·재무·산업 등 분석 분담).
- 적용 방법: 생성된 zip을 다운로드·압축 해제 → `스톡 에이전트` 폴더에 MD들 배치 → 코워크에서 해당 폴더 지정 → 프롬프트 입력("이란 전쟁으로 방산주 급등, 미국/한국 주식 추천")  → "에이전트 가이드에 따라 진행해" 지시. 에이전트 3개를 병렬 투입해 빠르게 리서치 후 종합 PDF 보고서 생성.
- 예약 작업: 코워크에서 "매주 월요일 장 시작 전 방산주 4종목 분석" 같은 스케줄을 등록 가능(단, 클로드 데스크탑 앱이 켜져 있을 때만 실행).

## 주요 주장 / 데이터
- 서브에이전트 MD 파일 생성 시 "오퍼스 4.6 + 확장 사고"를 쓰면 더 잘 만들어 준다고 권장 (자막상 모델명, 추정).
- 코워크는 클로드 코드와 달리 과거 대화 맥락을 다시 불러와 이어가기 쉬운 점을 장점으로 제시.
- 한글 깨짐 등 오류 발생 시 "MD 업데이트하고 PDF 다시 만들어 줘"처럼 재지시하면 자동 수정.
- 한계: 에이전트가 매수/매도 직접 추천은 막지만, 프롬프트로 강제화하면 우회 가능하다고 언급.
