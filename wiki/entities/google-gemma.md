# 구글 Gemma

구글의 경량 LLM 계열로, 이 위키에서는 온디바이스 실행이 가능한 모델(**Gemma 4**)로 등장한다.

## 이 위키에서의 등장
- 온디바이스에서 동작해 API 비용이 사실상 0이 된다는 점이 강조된다 (→ [[sources/youtube-rEamRUk7-pg|#12 Gemma 4 온디바이스]]).
- [[concepts/on-device-ai|온디바이스 AI]](온디바이스 AI)의 대표 사례로, 클라우드 API 의존을 줄이는 흐름의 근거로 제시된다 (→ [[sources/youtube-rEamRUk7-pg|#12 Gemma 4 온디바이스]]).

## 외부 검증 (2026-06-23, 웹)
- **확인 — Gemma 4는 실재하는 최신 버전.** "Gemma 4"는 자막 오인식이 아니라 실제 모델로, 2026년 3월 31일 출시됐다(Gemma 3은 2025년 3월의 이전 세대). 온디바이스 변형 **E2B/E4B**, 컨텍스트 **128K**(상위 모델 최대 256K), **140개+ 언어** 네이티브 학습, 텍스트·이미지·오디오·비디오 멀티모달 — 자막의 수치가 모두 부합한다 (→ https://blog.google/innovation-and-ai/technology/developers-tools/gemma-4/ , https://ai.google.dev/gemma/docs/releases ).
