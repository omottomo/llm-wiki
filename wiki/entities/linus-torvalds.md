# Linus Torvalds

## 한눈에 요약

- 리눅스를 만든 사람이자, 2005년 Git 개발을 이끈 인물이다.
- 이 위키에는 Git의 탄생 배경을 다루는 대목에서만 등장한다 (→ [[sources/gitbook-short-history-of-git|#45 Pro Git Git 역사]]).

## 이 위키가 근거로 삼은 것

Pro Git 1.2절은 딱 한 문장으로 그를 소개한다. BitKeeper 무료 사용권이 철회된 뒤 "리눅스 개발 공동체, 특히 리눅스를 만든 Linus Torvalds가" 자체 도구를 만들게 됐다는 대목이다. 그 도구는 BitKeeper를 쓰며 배운 교훈을 바탕으로 했다고 적는다 (→ [[sources/gitbook-short-history-of-git|#45 Pro Git Git 역사]]).

> 생년·국적·현재 활동 같은 신상은 이 위키가 흡수한 자료에 없다. 그래서 적지 않는다. 필요해지면 1차 자료를 하나 더 흡수한 뒤 채우는 게 맞다.
