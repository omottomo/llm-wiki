# Cursor

## 한눈에 요약

- AI 기능을 편집기 안에 넣은 **코드 에디터**다. 에이전트에게 작업을 맡기는 방식의 대표 도구 중 하나다.
- 터미널에서 도는 Claude Code와 사용 방식이 다르다. 이 위키에서는 주로 **기능을 견주는 비교 대상**으로 나온다.
- 이 도구 자체를 깊이 다룬 자료는 아직 흡수되지 않았다.

## 어떤 도구인가

AI 기반 코드 에디터이자 에이전틱 코딩 도구다. 이 위키에서는 주로 [[entities/claude-code|Claude Code]]와 기능을 비교하는 맥락에서 언급된다.
