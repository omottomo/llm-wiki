# Codex (OpenAI)

## 한눈에 요약

- OpenAI가 만든 **코딩 에이전트**다. Claude Code와 같은 자리를 놓고 겨루는 도구다.
- 다만 이 위키에서는 경쟁 상대보다 **함께 쓰는 짝**으로 더 자주 등장한다.
- 서로 다른 회사 모델은 서로 다른 곳에서 실수한다. 그래서 한쪽이 짠 코드를 다른 쪽에게 검토시키는 방식이 권장된다.

## 어떤 도구인가

[[entities/openai|OpenAI]]의 코딩 에이전트다. 이 위키에서는 [[entities/claude-code|Claude Code]]와 함께 쓰는 멀티 모델 협업의 짝으로 등장한다.

## 이 위키에서의 등장
- "Claude Code만 쓰면 망한다"는 주장과 함께, Codex를 병행해 서로의 약점을 보완하는 [[concepts/multi-model-workflow|멀티 모델 워크플로우]]가 제시된다 (→ [[sources/youtube-f0hcByvsyjU|#20 코덱스 멀티 모델]]).
- 이는 [[entities/boris-cherny|보리스 체르니]]의 "거의 바닐라 세팅" 입장과 대비되는 긴장점을 만든다 (긴장③, → [[sources/youtube-f0hcByvsyjU|#20 코덱스 멀티 모델]]).
