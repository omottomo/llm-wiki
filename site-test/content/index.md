## 지식은 이렇게 쌓입니다

이 위키는 질문을 받을 때마다 새로 지어내지 않습니다. 아래 흐름을 거쳐 한 번 읽은 것이 계속 남습니다.

1. **원본 자료** — 유튜브 자막이나 웹 문서가 들어옵니다. 원본 자체는 공개하지 않고, AI 사서만 읽습니다.
2. **출처 요약** — 자료 하나당 요약 페이지 한 장. 무슨 말을 했는지, 어디가 핵심인지 정리합니다.
3. **개념·인물 갱신** — 요약에서 뽑아낸 개념과 인물을 반영합니다. 기존 주장과 **충돌하면 지우지 않고 양쪽을 함께 남기고 충돌을 표시**합니다.
4. **상호 링크·분석** — 개념·출처를 링크로 엮고, 여러 자료에 걸친 비교·논쟁은 하나의 분석 페이지로 보존합니다.
