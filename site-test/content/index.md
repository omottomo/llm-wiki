# LLM 위키

**AI 사서(librarian)가 운영자가 고른 자료를 읽고 직접 만들고 관리하는 위키입니다.** [카파시의 LLM 위키 실험](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)에서 착안했으며, 특정 매체나 재생목록에 국한되지 않습니다.
현재의 중심 주제는 Claude Code를 중심으로 한 AI 에이전트 코딩, 그리고 그것을 제대로 다루기 위한 환경 설계(하네스 엔지니어링)입니다.
유튜브 영상이든 웹 문서든 자료 하나를 흡수할 때마다 AI가 요약본을 남기고, 거기서 뽑아낸 개념과 인물을 기존 페이지에 이어 붙이는 방식으로 계속 자라납니다.

> **읽기 전 알아두세요.** 출처의 상당수는 사람이 쓴 글이 아니라 유튜브 영상의 **자동생성 자막**입니다. 그래서 인명·회사명·수치가 잘못 들린 채로 옮겨졌을 수 있으며, 확인된 부분은 본문에 교정·추정 표기를 남겨 두었습니다.

## 지식은 이렇게 쌓입니다

이 위키는 질문을 받을 때마다 새로 지어내지 않습니다. 아래 흐름을 거쳐 한 번 읽은 것이 계속 남습니다.

1. **원본 자료** — 유튜브 영상(자동생성 자막)이나 웹 문서가 들어옵니다. 원본 자체는 공개하지 않고, AI 사서만 읽습니다.
2. **출처 요약** — 자료 하나당 요약 페이지 한 장. 무슨 말을 했는지, 어디가 핵심인지 정리합니다.
3. **개념·인물 갱신** — 요약에서 뽑아낸 개념과 등장 인물·조직을 해당 페이지에 반영합니다. 새 내용이 기존 주장과 **충돌하면 지우지 않고 양쪽을 함께 남기고 충돌을 표시**합니다.
4. **상호 링크** — 개념끼리, 개념과 출처끼리 링크로 엮어 어디서 나온 이야기인지 따라갈 수 있게 합니다.
5. **분석** — 여러 자료에 걸친 비교·논쟁을 하나의 분석 페이지로 보존합니다. 위의 가이드 세 편이 그 결과물입니다.
